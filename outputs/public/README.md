# Driver 1003 public artifact package

This directory is the repository's reviewed public boundary. It contains only:

- the presentation-first RCCI and behavior report;
- the generalized POI/route verification map;
- the privacy-filtered behavior-insight JSON;
- the road-class longitudinal summary used by the report's early/middle/late
  comparison;
- this policy note and a deterministic integrity manifest.

Trip-level records, exact cluster coordinates, enriched private POI tables,
Google response caches, and granular recurrence/OD CSVs are deliberately
excluded. The home location is generalized in every public artifact.

Named non-home places and route patterns can still be identifying when combined
with outside information. Technical validation does not replace participant
consent, IRB requirements, data-use agreements, or manual visual review.

Open `driver_1003_route_choice_change_index_report.html` first. Its verification
map link stays inside this directory.

The CSV is public only because it contains aggregate road-class statistics, not
trip records, coordinates, addresses, or API responses. Regenerate the package
from an approved restricted workspace, then run the manifest and validator
commands in [`outputs/README.md`](../README.md).
