# Results guide

Open `outputs/public/driver_1003_route_choice_change_index_report.html` first.
It is written for non-specialists; the verification map and JSON are supporting
artifacts, not independent evidence of personal facts.

## How to read the report

1. **Key research insights** state only findings that survived the project’s
   relevance and uncertainty review.
2. **Likely home area** is neighborhood-level by design. It indicates a
   recurring nighttime return and morning departure area, never a residence.
3. **Frequently visited places and routine** combine repeated timing with map
   context. “Possible” and “likely” convey different evidence strength.
4. **Route change stories** use named corridors and road classes. A high RCCI
   can reflect a route change, a destination change, sparse observation, or a
   combination; read the OD context before interpreting it.
5. **Long-term timeline** distinguishes adoption, stabilization, reversion, and
   temporary deviations when evidence permits.

## Confidence and limitations

High confidence means multiple independent behavioral and map-context signals
agree; it is not ground truth. Medium and low confidence findings should guide
manual map review, not be reported as personal facts. Destination proximity,
parking lots, access roads, incomplete listings, and missing recording periods
remain material limitations.

## Public artifacts

`outputs/public/README.md` explains the reviewed artifact set and
